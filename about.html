About islandprodata

islandprodata is a small independent data-publishing project that turns large, freely available business datasets into clean, structured, ready-to-use products. We slice a single global company dataset by industry and country, cap each slice at 50,000 rows, and deliver it as CSV + JSON with a free 500-row preview on every page.

Who runs this

The project is operated by islandprodata, an individual developer and data engineer. The code that builds and publishes these pages is open source and lives in the islandprodata GitHub organization — each dataset has its own repository containing the sample file and preview image.

Source data

Our source is a single large, freely available company dataset (originally ~32 million records spanning 147 industries and 222 countries). We extract, clean, and cap slices for each product. The ten columns shipped in every dataset are:

  • country, founded, id, industry, linkedin_url, locality, name, region, size, website

Fields such as founded and website are sometimes empty because that is how the source data is — we do not fabricate values.

Expertise

We specialize in data extraction, deduplication, schema normalization, and building lightweight static landing pages that let buyers preview a dataset before purchasing. Every page is generated programmatically from a single template, so the field reference, preview image, and searchable sample table are always in sync with the underlying data.

Our mission

Make high-quality, structured B2B data affordable and easy to evaluate. Pricing is simple: $2 per 10,000 records, rounded up to whole dollars, with a free sample on every page.
